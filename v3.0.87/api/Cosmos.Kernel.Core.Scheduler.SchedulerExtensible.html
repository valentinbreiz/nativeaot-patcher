SchedulerData

Scheduler-specific data. Each scheduler defines its own class and stores an instance here from its IScheduler lifecycle hooks (InitializeCpu(PerCpuState), OnThreadCreate(PerCpuState, SchedulerThread)), and clears it again in ShutdownCpu(PerCpuState) and OnThreadExit(PerCpuState, SchedulerThread).

One slot is the whole budget: a policy needing several values defines one class holding them. A policy swap moves every live thread with it: SetScheduler(IScheduler) hands each one to the outgoing policy's OnThreadExit(PerCpuState, SchedulerThread) and then to the incoming policy's OnThreadCreate(PerCpuState, SchedulerThread), so a hook is never handed a record another policy wrote.

Read it with as, never a cast, all the same: a hook can still meet an empty slot, because OnThreadExit(PerCpuState, SchedulerThread) clears it and a thread can lose its record between a tick and the hook that observes it. A cast that fails does so inside the timer interrupt, and as costs nothing on a hook that handles null anyway.
