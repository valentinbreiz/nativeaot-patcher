Class ArpPacketEthernet

Namespace
Cosmos.Kernel.System.Network.ARP
Assembly
Cosmos.Kernel.System.dll

Represents an ARP packet for IPv4 over Ethernet: hardware type 1, protocol type 0x0800, with 6-byte hardware and 4-byte protocol addresses. The address properties are snapshots parsed from RawData once, at construction, and are never re-read afterwards.
