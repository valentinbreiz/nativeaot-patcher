Address4

Represents a IPv4 address.

IPPacket

An IPv4 packet over Ethernet. The build constructors write the complete IPv4 header, including the header checksum, at construction time; the checksum is never recomputed, so the header bytes must not be modified afterwards. Derive from this class to implement a custom IP protocol that only IPv4 carries: pass the protocol number and payload length to a build constructor and write the payload into RawData from DataOffset onward. A protocol that both versions carry composes an InternetPacket instead of deriving from this class, the way UdpPacket and TcpPacket do.
