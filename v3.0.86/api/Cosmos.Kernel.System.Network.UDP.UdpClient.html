Parameters

How many consecutive ports to try before giving up.

Returns

ushort

A port no live client is bound to, or 0 when tries consecutive candidates were all taken. Zero is not a usable port, but it is also what an unbound client reports, so a caller that keeps the value must not later read it back as a binding.

ReceivePacket(int)

Waits for a datagram to arrive on this client's local port and returns the parsed UdpPacket itself, without re-parsing. Unlike Receive(ref EndPoint, int), which returns the payload bytes alone, the returned packet exposes the ports, the source and destination addresses, and the payload. Polls the receive buffer in 10 millisecond slices.
