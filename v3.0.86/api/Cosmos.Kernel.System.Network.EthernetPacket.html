Class EthernetPacket

Cosmos.Kernel.System.Network

Cosmos.Kernel.System.dll

An Ethernet frame, the root of the packet hierarchy. The frame lives in RawData; every header property is a snapshot parsed from that buffer at construction time and is not refreshed by later writes to the buffer. Derived types lay their headers into the same buffer from their constructors, including checksums: there is no separate finalize-before-send step.
