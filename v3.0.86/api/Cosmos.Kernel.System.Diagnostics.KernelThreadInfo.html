Struct KernelThreadInfo

Namespace
Cosmos.Kernel.System.Diagnostics
Assembly
Cosmos.Kernel.System.dll

Point-in-time snapshot of one kernel thread, produced by SchedulerInfo. The snapshot is taken without locking the scheduler, so fields of a thread that is being rescheduled concurrently may be one tick stale.

This is a projection of SchedulerThread, the thread control block on the experimental scheduler seam, and it is narrower on purpose. It carries what a monitor can render off an unlocked read: identity, state, and two totals. It leaves behind the saved stack pointer, the entry address, the stack base and the two scheduling timestamps, because each of those is meaningful only in a state the snapshot cannot guarantee it is observing, and a policy that wants them already holds the control block. Two names differ from the seam's, both to state a unit the seam leaves to its own docs: TotalRuntimeNs and StackSizeBytes.
