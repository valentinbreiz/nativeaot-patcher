DhcpRelease(Address, Address, MACAddress)

Initializes a new instance of the DhcpRelease class, addressed to the DHCP server's unicast IP address rather than broadcast. Writes DHCP option 53 (message type) with value 7, DHCPRELEASE, then option 54 (server identifier) carrying server, then option 61 (client identifier) carrying the Ethernet hardware type and source, then the end mark.

public DhcpRelease(Address client, Address server, MACAddress source)

Parameters

client Address

The client's currently assigned IPv4 address, used as the source.

server Address

The DHCP server's IPv4 address, used as the destination and written to option 54.

source MACAddress

The MAC address of the sending network device, written to option 61.
