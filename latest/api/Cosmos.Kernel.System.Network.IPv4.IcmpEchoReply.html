Constructors

IcmpEchoReply(IcmpEchoRequest)

Initializes a new instance of the IcmpEchoReply class, building a reply to request: source and destination are swapped, and the identifier, sequence number, and payload are copied from the request. The checksum is computed here and never recomputed.
