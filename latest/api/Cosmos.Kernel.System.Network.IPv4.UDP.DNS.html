DnsAnswer

A DNS resource record parsed from the answer section of a response. Instances are parse products created by DnsPacketAnswer, not builder inputs.

DnsClient

Used to manage a DNS connection to a server.

DnsPacket

Represents a DNS message carried over UDP (RFC 1035). The DNS header fields (transaction ID, flags and section counts) are snapshots parsed from the raw buffer at construction and are never recomputed.

DnsPacketAnswer

A DNS response packet. The full parse (header counts, question and answer sections, and compression-pointer resolution) runs inside the constructor.

DnsPacketQuery

A DNS query packet that composes a single A/IN question for a given domain name.

DnsQuery

A DNS question parsed from the question section of a response. Instances are parse products created by DnsPacketAnswer, not builder inputs.
