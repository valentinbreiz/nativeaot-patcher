Kernel debug log, written to the platform serial port (COM1 on x64, PL011 on ARM64). This is the supported way for kernels to emit debug output that a host can capture; on QEMU the stream appears on the -serial device. Writes are synchronous, allocation-free for strings and numbers, and usable from the earliest phase of BeforeRun onward.

Write(params ReadOnlySpan<object?>)

Writes each value in order: strings and characters as text, integers in decimal, bytes and byte arrays in hexadecimal, booleans as true/false, null as null, and anything else via ToString(). The argument list itself costs nothing: the compiler builds it on the stack. A value type passed here is still boxed, which does allocate, so prefer WriteString(string) and the WriteNumber overloads on allocation-sensitive paths.

WriteBytes(ReadOnlySpan<byte>)

Writes raw bytes to the log stream as one uninterrupted sequence. Interrupts are masked for the duration of the write, so traces logged from IRQ handlers cannot interleave into the middle of the data. Use this for binary wire formats that share the serial port with text output, such as the kernel test protocol.
