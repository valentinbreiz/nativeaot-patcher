Describes the point of view used for 3D drawing on a Canvas3D. The aspect ratio always comes from the canvas mode, so a camera only carries where it stands, what it looks at, and its field of view.

Remarks

A default-initialized camera is still usable: Up falls back to UnitY and FovY to 60 degrees when left unset, so object initializers may set only the members they care about. The members are init-only: a camera is replaced rather than edited, because Camera hands back a copy and the backend only reloads its transforms when the property is assigned.
