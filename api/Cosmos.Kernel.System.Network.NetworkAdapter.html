A handle to one of the network devices HAL enumeration registered. Obtained from GetAdapter(int) or Primary, and handed back to the ring to inspect that device or to configure it with Enable(NetworkAdapter, Address, Address, Address).

Remarks

The handle carries the device's registration index biased by one, so a default-constructed value names no device rather than silently naming the first one.
