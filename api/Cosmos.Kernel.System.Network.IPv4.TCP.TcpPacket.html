Class TcpPacket

Namespace
Cosmos.Kernel.System.Network.IPv4.TCP
Assembly
Cosmos.Kernel.System.dll

Represents a TCP segment carried in an IPPacket. Header properties are snapshots parsed from RawData at construction and are never recomputed; the checksum of a locally built segment is likewise computed once, in the constructor, so mutating the raw bytes afterwards leaves it stale.
