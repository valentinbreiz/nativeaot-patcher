Address

Represents an IP address: an Address4 or an Address6.

EthernetPacket

An Ethernet frame, the root of the packet hierarchy. The frame lives in RawData; every header property is a snapshot parsed from that buffer at construction time and is not refreshed by later writes to the buffer. Derived types lay their headers into the same buffer from their constructors, including checksums: there is no separate finalize-before-send step.

MaskedAddress

The result of masking an address: its bytes, most significant first, indexable by octet. A stack-only value, so it is never boxed or stored.

NetworkAdapter

A handle to one of the network devices HAL enumeration registered. Obtained from GetAdapter(int) or Primary, and handed back to the ring to inspect that device or to configure it with Enable(NetworkAdapter, Address, Address, Address).
