Class UdpPacket

Namespace
Cosmos.Kernel.System.Network.IPv4.UDP
Assembly
Cosmos.Kernel.System.dll

Represents a UDP datagram carried in an IPPacket. Header properties are snapshots parsed from RawData when the packet is constructed; they are not re-read afterwards. The UDP checksum field is written as zero and never computed, which is legal for UDP over IPv4.

UdpPacket(Address, Address, ushort, ushort, ushort)

Creates a UDP packet with an uninitialized payload area of dataLength bytes. The Ethernet, IP, and UDP headers, including all length fields and the IP header checksum, are written during construction and never recomputed, so the payload must be filled in before the packet is sent. The UDP checksum is written as zero and never computed, which is legal for UDP over IPv4.
