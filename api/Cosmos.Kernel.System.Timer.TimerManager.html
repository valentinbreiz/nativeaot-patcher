Frequency

Tick frequency of the timer device in Hz, or 0 when no device is registered, which IsInitialized reports and an assignment made in that state does nothing. Assigning reprograms the device, which divides a fixed input clock, so the value read back is the nearest tick the divisor can express rather than the value assigned. A frequency the device cannot divide to at all is refused rather than silently dropped.

public static uint Frequency { get; set; }

Property Value

uint

Exceptions

InvalidOperationException

Timer support is disabled.

ArgumentOutOfRangeException

The timer device cannot run at this frequency. Each device divides a fixed counter, so each accepts from that counter divided by its widest divisor up to the counter itself: 19 Hz to 1193180 Hz on the x64 PIT, and 1 Hz up to CNTFRQ_EL0 on the ARM64 generic timer.

Schedule(Action, TimeSpan)

Schedules a callback to run once after the specified delay. The callback runs in interrupt context, so it must not block, and it must not let an exception escape: nothing above the interrupt dispatch catches one and the kernel halts. Use Schedule(Action, TimeSpan) for callbacks that need thread context.

public static SoftwareTimer? Schedule(Action callback, TimeSpan delay)

Parameters

callback Action

Method to invoke when the delay expires.

delay TimeSpan

Delay before the timer fires. The timer device's tick is the resolution, so a delay shorter than one tick, and a zero or negative delay, fire on the next tick.

Returns

SoftwareTimer

The scheduled timer, or null if no timer device is registered.

ScheduleRecurring(Action, TimeSpan)

Schedules a callback to run repeatedly with the specified period. The callback runs in interrupt context under the same rules as Schedule(Action, TimeSpan); use ScheduleRecurring(Action, TimeSpan) for callbacks that need thread context.

public static SoftwareTimer? ScheduleRecurring(Action callback, TimeSpan period)

Parameters

callback Action

Method to invoke each period.

period TimeSpan

Period between firings; must be positive. The timer device's tick is the resolution, so a period shorter than one tick fires on every tick.

Returns

SoftwareTimer

The scheduled timer, or null if no timer device is registered or the period is not positive.
