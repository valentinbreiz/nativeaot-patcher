DnsPacketAnswer(byte[])

Parses a DNS response from a received frame. The buffer is aliased without copying. The whole message is parsed during construction: header counts, the question and answer sections, and compression pointers; malformed input throws (typically IndexOutOfRangeException). When the reply code is not OK, section parsing is skipped and Queries and Answers stay null.
