Represents a DNS message carried over UDP (RFC 1035). The DNS header fields (transaction ID, flags and section counts) are snapshots parsed from the raw buffer at construction and are never recomputed.

DnsPacket(Address, Address, ushort, ushort)

Composes the UDP and DNS headers of a query between ports 53: a transaction ID taken from a static 8-bit counter (only the low byte is ever populated), flags 0x0100 (recursion desired), urlnb questions and zero answer, authority and additional records. The question section itself is written by subclasses. Lengths and checksums are computed by the base constructors at construction and never recomputed.
