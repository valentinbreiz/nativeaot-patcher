Cell-based graphics console for kernel output. Uses a character grid (cells) similar to Aura OS for efficient terminal rendering. Can be instantiated on any canvas (hardware or virtual).

Initialize()

Initializes the default (global) console on the hardware framebuffer. Idempotent: a second call leaves the existing console in place, so a kernel that overrides OnBoot() may call this whether or not it also called base.OnBoot().
