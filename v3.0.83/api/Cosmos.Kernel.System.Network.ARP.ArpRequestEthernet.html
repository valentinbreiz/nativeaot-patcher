ArpRequestEthernet(MACAddress, Address, MACAddress, Address, MACAddress)

Initializes a new 42-byte ARP request for sending. Callers normally pass Broadcast as targetMac (the Ethernet destination) and None as arpTargetMac: the target hardware address field of a request is zero because it is the value being asked for.

public ArpRequestEthernet(MACAddress ourMac, Address ourIP, MACAddress targetMac, Address targetIP, MACAddress arpTargetMac)

Destination MAC address of the Ethernet frame, normally Broadcast.
