Remarks

The driver still receives the index as its source string, because IVfsFilesystemType lives in the HAL and cannot name a Partition. Resolving it here rather than at the call site is what closes the window in which a rescan renumbers the list.

TryRename(string, string)

Renames oldFullPath to newFullPath, replacing an existing destination of the same kind (an existing destination directory must be empty). Refuses mount points, renames into the source's own subtree, and cross-mount renames. The destination survives a failed rename, and a destination that is still open goes delete-pending instead of being dropped under its handles.

public static bool TryRename(string oldFullPath, string newFullPath)

Parameters

oldFullPath string

Absolute path of the entry to move.

newFullPath string

Absolute path it should have afterwards.

Returns

bool

false when either path is a mount point, the source does not exist, the destination is inside the source's own subtree, the two sit on different mounts, the two are of different kinds, the destination is a directory that is not empty, or the driver refuses the move. Renaming a path onto itself succeeds.
